入门路线 ​

这份知识库按“先建立概念，再理解模型，最后进入工具和专题”的顺序组织。零基础用户不必一次学完所有术语，先知道每一层解决什么问题即可。

第一步：建立 AI 基础 ​

先阅读 AI 基础概念，理解下面几组区别：

  • AI、机器学习、深度学习和模型不是同一个概念。
  • 训练负责形成能力，推理负责在使用时生成结果。
  • Token 是文本处理单位，上下文窗口决定模型一次能看到多少信息。
  • Embedding 把内容转换成可比较的向量，常用于语义检索。

这一阶段的目标不是记定义，而是知道模型为什么有能力、成本和边界。

第二步：理解 LLM 理论 ​

按顺序阅读：

  1. 大模型入门：认识 LLM 的能力、幻觉和常见应用形态。
  2. Transformer 直觉：理解 Attention 如何利用上下文。
  3. 训练、微调与对齐：区分预训练、指令微调、对齐和 RAG。
  4. RAG 与 Agent：理解模型如何连接外部知识和工具。

这一阶段不要求推导公式，但要能说明“模型内部能力、外部资料和工具调用”各自负责什么。

第三步：学习 Prompt 与工具 ​

Prompt 不是魔法句式，而是任务说明。阅读 Prompt 入门 后，至少要能写清：

  • 目标：要模型完成什么。
  • 背景：模型完成任务需要哪些材料。
  • 约束：必须遵守什么，不能做什么。
  • 输出格式：结果应该怎样组织。
  • 完成标准：如何判断结果可用。

再通过 常用工具 区分 Web AI 助手、API、本地模型、RAG/Agent 工具和 AI 绘画界面，不要把工具界面和模型能力混为一谈。

第四步：进入 AI 绘画专题 ​

如果主要目标是图像生成，再学习：

  • 底模是什么 与 模型组成。
  • 基本原理 与 常见模型生态。
  • LoRA 入门 和 工作流与模板。

先跑通最小文生图流程，再逐步加入 LoRA、ControlNet、局部重绘和放大流程。每次只改变少量变量，更容易定位失败原因。

第五步：建立自己的资料体系 ​

最后浏览 常用网站、精选教程 和 术语表，并为自己使用的重要资源记录：

  • 来源、版本和更新时间。
  • 模型卡、许可证与用途限制。
  • 有效 Prompt、参数和失败案例。
  • 工作流依赖、节点版本与复现条件。

常见误区 ​

  • 只背参数和提示词，不理解模型、数据和工具之间的关系。
  • 把模型生成的流畅回答当成已经验证的事实。
  • 认为接入 RAG 或 Agent 后就会自动可靠，忽略检索质量、权限和失败路径。
  • 一开始就堆复杂工作流，导致问题无法定位。
  • 忽略数据、模型、素材、API 和平台许可证。
