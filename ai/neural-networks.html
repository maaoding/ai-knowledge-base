神经网络直觉 ​

一句话结论： 神经网络把许多可调的计算单元分层连接起来，通过损失函数提供方向，再用反向传播和梯度下降逐步调整权重与偏置；“深”换来自动学特征，容量越大越要防过拟合。

前置知识 ​

  • 已阅读 机器学习入门，理解特征、标签、训练、验证和泛化。
  • 知道模型参数是在训练中调整的数字。
  • 不要求微积分基础；本页只解释计算方向，不推导偏导数和链式法则。

学习目标 ​

读完后，你应该能够：

  • 解释神经元、层、权重和偏置分别做什么。
  • 说明为什么神经网络需要激活函数。
  • 按顺序描述前向计算、损失计算、反向传播和参数更新。
  • 区分损失函数、梯度与梯度下降。
  • 把 MLP、CNN、RNN、Transformer 与典型任务大致对应起来。
  • 说出网络层面防止过拟合的三种常用手段。
  • 说明神经网络与深度学习之间的关系。

核心概念 ​

神经元、权重和偏置 ​

人工神经元不是生物神经元的完整模拟，而是一个可训练的计算单元。它先对输入做加权求和，再加上偏置：

text
z = w1*x1 + w2*x2 + ... + wn*xn + b
输出 = 激活函数(z)
  • x 是输入特征或上一层输出。
  • w 是权重（Weight），决定每个输入影响有多大、方向是正还是负。
  • b 是偏置（Bias），让神经元不必在所有输入为零时也固定输出零。

训练神经网络的核心，就是找到一组能让预测误差更小的权重和偏置。

为什么要“深”：分层表示的直觉 ​

神经元通常按层组织：

  • 输入层：接收原始特征，本身通常不做复杂学习。
  • 隐藏层：逐层组合输入，形成更抽象的表示。
  • 输出层：产生分类概率、数值或其他任务输出。

单看一个神经元，它对输入做加权求和，线性单元的决策边界只能是一条直线（高维下是一个平面），所有情况都要被这一刀切开。激活函数让边界能弯起来，而层数让特征能一层层变抽象：每一层都在前一层输出的基础上继续组合。以识别一张猫图为例：

text
像素 → 边缘与色块 → 眼睛、耳朵等形状 → 头部、身体等部件 → “这是一只猫”

浅层做局部组合，深层对应抽象概念，中间没有哪一层是人为指定的。深度学习（Deep Learning）通常指使用多层神经网络从数据中学习这种分层表示的方法——“深”描述的是网络结构层次，不代表模型拥有更深刻的主观理解。

关键取舍在这里：过去做图像识别，要靠人手工设计特征（边缘怎么检测、形状怎么描述），再把特征喂给分类器；多层网络把“找特征”这一步也交给了训练。深，换来的是自动学特征，代价是参数更多、更依赖数据量和优化技巧。这正是后面大模型与扩散模型共同的地基——它们都是深网络，只是学的对象和生成方式不同。

常见网络家族一览 ​

同样是“分层网络”，不同数据的结构差别很大，于是演化出几类常见家族。本页讲的神经元和层是最通用的零件，按不同方式组装，就成了这几类：

  • MLP（多层感知机，Multilayer Perceptron）：每层神经元与上一层的全部神经元相连（全连接），输入是一维特征向量。结构最简单、最通用，后面最小推演训练的就是它的单个神经元；表格数据和小型分类任务常用它打底。
  • CNN（卷积神经网络，Convolutional Neural Network）：用小的卷积核在图像上滑动扫描。它抓住两条图像特有的先验：每个神经元只看一小块局部区域（局部视野），同一组权重在整张图上重复使用（权重共享）。参数因此远少于同等全连接网络，是图像识别的经典选择，AI 绘画早期的去噪网络也以卷积结构为主。
  • RNN（循环神经网络，Recurrent Neural Network）：按时间步循环处理序列，每一步把上一步的计算结果带进下一步，适合逐词读入的文本与时序数据；代价是必须顺序计算、难以并行，远距离信息一路传递容易衰减。
  • Transformer：用注意力让序列中任意两个位置直接互相查看，不必逐步传递，整个序列还能并行计算。2017 年提出后逐渐取代 RNN 成为序列任务的主流，也是大语言模型的底座。

选家族的本质，是让网络结构匹配数据的结构：图像有局部性，序列有前后依赖，长程依赖与并行训练的需求把主流推向了 Transformer。注意力机制的直觉展开见 Transformer 直觉。

激活函数 ​

如果每层都只做线性加权，多层线性计算仍可合并成一次线性计算，网络很难表示弯曲的决策边界。激活函数（Activation Function）引入非线性。

常见函数包括：

  • ReLU：负数输出 0，正数保持不变；常用于隐藏层。
  • Sigmoid：把数值压到 0 与 1 之间；常用于二分类输出，但深层隐藏层中可能出现梯度过小。
  • Tanh：把数值压到 -1 与 1 之间。
  • Softmax：把一组原始分数（Logit，后面的推理与解码页会细讲）转成总和为 1 的概率，常用于输出层。

激活函数的选择会影响表达能力、梯度传播和训练稳定性。

前向计算 ​

前向计算（Forward Pass）是从输入到输出依次计算：

  1. 输入进入第一层。
  2. 每个神经元计算加权和与激活值。
  3. 当前层输出成为下一层输入。
  4. 输出层给出最终预测。

推理阶段主要执行前向计算。训练阶段在前向计算后，还要比较预测与目标并更新参数。

损失函数 ​

损失函数（Loss Function）把“预测有多不对”变成一个可优化的数值。

  • 回归任务常用均方误差或平均绝对误差。
  • 分类任务常用交叉熵。
  • 生成模型会根据训练目标使用 Token 级交叉熵或其他损失。

损失越小通常表示模型更符合当前训练目标，但不代表真实业务一定更好。数据偏差、错误标签和不合适的目标函数都可能让“低损失”与“有用”分离。

优化：梯度下降与优化器 ​

**梯度（Gradient）**可以直观理解为：某个参数稍微变化时，损失会朝哪个方向、以多快速度变化。

**反向传播（Backpropagation）**从输出层向前计算每个参数对损失的影响。它高效复用了链式法则中的中间结果，本身负责“算梯度”。

**梯度下降（Gradient Descent）**使用这些梯度更新参数：

text
新参数 = 旧参数 - 学习率 * 梯度

学习率决定每次走多大一步（见术语表 学习率）。太大可能越过较好位置甚至发散，太小则训练缓慢。

一个现实问题：数据量大时，“每次用全部数据算准梯度再走一步”太慢。实际训练用小批量梯度下降（Mini-batch SGD）——每次只取一小批样本估计梯度就走一步。**batch size（批大小）**就是这一批有多少样本：批越大，估计出的方向越稳，但算一步的成本越高、同样轮数里的更新次数越少；批越小，方向噪声越大，这种噪声有时反而帮训练跳出不好的位置。batch size 与学习率、训练轮数一样，属于训练开始前人工设定的超参数。

在“按梯度走”的框架内，优化器决定每一步具体怎么迈：

  • SGD（随机梯度下降）：按当前批的梯度直接走。简单可靠，但损失面忽陡忽缓时，步子容易来回震荡。
  • 动量（Momentum）：给更新加惯性——新一步的方向不只看当前梯度，还保留一部分上一步的方向。像小球滚下坡，来回的小抖动被惯性抹平，方向一致的坡段则越走越快。
  • Adam：在动量之外，再为每个参数记录梯度的历史大小，自动调整各参数的步长——梯度长期很大的参数走小步，梯度长期很小的参数走大步，相当于每个参数有自己的步长。它对学习率不那么敏感，是很多模型训练的默认起点。

训练后期还会配合学习率调度（Learning Rate Schedule）：先用大步子快速接近，再逐步调小做精细收敛——先赶路，后落地。这些机制都仍在“算梯度、走步子”的框架内，只是把每一步走得更稳更快；它们弥补不了错误的数据或错误的目标。

过拟合与正则化 ​

机器学习入门讲过什么是过拟合：模型把训练数据连噪声一起背下来，新数据上表现反而变差（词条见术语表过拟合）。从网络的角度看，根源在容量：参数越多，网络越有能力把训练集逐条记住，而不是提炼规律——背下一万道题，比学会一种解法容易得多。

网络层面常用的三件正则化（Regularization）工具：

  • Dropout（随机失活）：训练时每一步随机让一部分神经元暂时“下班”，下一步再随机换一批。任何一条通路都可能在某一步被切断，网络就不能把关键特征全押在一两个神经元上，被迫把信息摊开、多路冗余；也相当于同时训练了许许多多不同子网络的组合。
  • 早停（Early Stopping）：盯着验证损失，训练损失还在降、验证损失开始回升时就停——回升说明模型已经开始“背题”。这是最便宜的正则化，只需要留一份验证数据并随时保存进度。
  • 权重衰减（Weight Decay）：给损失加上“权重别太大”的惩罚，训练时微微把权重往零的方向拉。权重整体偏小，意味着单个输入的波动不会让输出剧烈变化，模型对噪声没那么敏感。

三者指向同一件事：别让网络把全部能力用来贴合训练集的每个细节。用不用、用多少，由验证集的表现说了算，不靠感觉。

最小推演：训练一个神经元 ​

假设一个神经元有两个输入：

text
x1 = 1.0, x2 = 0.5
w1 = 0.8, w2 = -0.4, b = -0.1

使用 ReLU 激活：

text
z = 0.8*1.0 + (-0.4)*0.5 - 0.1 = 0.5
预测值 = ReLU(0.5) = 0.5

若目标值是 1.0，使用平方误差：

text
损失 = (预测值 - 目标值)^2 = (0.5 - 1.0)^2 = 0.25

在这个位置，增大 w1 会让预测更接近目标。若学习率为 0.1，梯度计算得到 w1 的梯度为 -1.0（对平方误差，w1 的梯度 = 2×(预测−目标)×输入 = 2×(0.5−1.0)×1.0 = −1.0），则：

text
新 w1 = 0.8 - 0.1*(-1.0) = 0.9
新预测 = ReLU(0.9 - 0.2 - 0.1) = 0.6
新损失 = (0.6 - 1.0)^2 = 0.16

一次更新后损失从 0.25 降到 0.16。不过刚才为了聚焦，只更新了 w1、把 w2 固定在 -0.4——真实训练不挑食：在同一个位置上，每个参数都有自己的梯度，并且各自按自己的梯度同时更新。

回到最初的起点（w1 = 0.8, w2 = -0.4，预测仍是 0.5）。w2 的梯度用同一个公式，只是把它对应的输入 x2 换进来：

text
w2 的梯度 = 2×(预测 - 目标)×x2 = 2×(0.5 - 1.0)×0.5 = -0.5

它只有 w1 梯度（-1.0）的一半，原因很直观：x2 = 0.5 只有 x1 一半大——输入影响小，参数拨动输出的杠杆就短。两个参数同时更新：

text
新 w1 = 0.8 - 0.1*(-1.0)  = 0.9    （与第一轮相同）
新 w2 = -0.4 - 0.1*(-0.5) = -0.35

第二轮前向，把两个新值都用上：

text
z = 0.9*1.0 + (-0.35)*0.5 - 0.1 = 0.625
预测值 = ReLU(0.625) = 0.625
损失 = (0.625 - 1.0)^2 ≈ 0.141

同时更新两个参数，损失从 0.25 降到约 0.141，比只动 w1（0.16）降得更低——每个参数都在用自己的梯度为“靠近目标”出力。真实网络就是把这套动作在大量参数、大量批次上重复；单次下降不保证最终一定泛化良好。

对比表 ​

把本页的核心概念放在一起对比：

概念回答的问题是否在训练中变化常见误解
权重（Weight）某个输入影响多大、方向如何是权重越大就一定越重要
偏置（Bias）整体激活门槛如何平移是与数据偏见或公平性中的 bias 完全相同
激活函数如何引入非线性或形成输出范围通常否任意激活函数都能互换
损失函数当前预测离训练目标多远公式通常固定，数值变化损失低就一定满足业务目标
梯度参数微调会怎样影响损失每步重新计算梯度就是参数更新后的值
优化器如何根据梯度更新参数状态会变化优化器能自动解决数据和目标错误

常见误区 ​

  • “神经元像人脑一样思考”：人工神经元是受启发的数学单元，不等同于生物神经系统。
  • “层数越多越好”：更深的网络需要合适的数据、结构、优化和正则化。
  • “反向传播就是梯度下降”：反向传播计算梯度，梯度下降或其他优化器使用梯度更新参数。
  • “激活函数只改变输出范围”：它还决定网络能否表达非线性关系，并影响梯度传播。
  • “训练损失下降就完成了”：还要检查验证指标、过拟合、鲁棒性和真实场景表现。
  • “Bias 一定指社会偏见”：本页 Bias 是神经元参数；数据偏差与公平性是另一层问题。
  • “参数越多模型越聪明”：参数量只决定表达能力的上限，效果还要看数据量、结构和训练方法；数据不够时，大网络反而更容易过拟合。
  • “学习率调好了就不用管 batch size”：两者互相牵扯——batch size 决定用多少样本估计方向，方向的噪声程度变了，合适的学习率也跟着变；调参时通常放在一起考虑。

自测问题 ​

1. 为什么多层网络不能全部省略激活函数？ ​

查看答案

因为多层纯线性变换仍可合并成一次线性变换，无法表达复杂的非线性关系。激活函数让网络形成弯曲、分段或更复杂的映射。

2. 反向传播和梯度下降分别负责什么？ ​

查看答案

反向传播高效计算各参数对损失的梯度；梯度下降或其他优化器根据梯度和学习率更新参数。

3. 训练损失持续下降而验证损失开始上升，最可能说明什么？ ​

查看答案

最可能出现了过拟合：模型继续适应训练数据的细节，却降低了对未见数据的泛化能力。

4. 图像识别、早期的序列任务和大语言模型，分别常用哪类网络？为什么？ ​

查看答案

图像常用 CNN：局部视野加权重共享，匹配“特征与出现位置无关”的图像结构；早期序列任务常用 RNN：按时间步逐个读入，天然带上前后状态；大语言模型几乎都用 Transformer：注意力让任意两个 Token 直接互相查看，支持并行训练，也解决了长距离依赖。选型的本质是让网络结构匹配数据的结构。

5. 第二轮推演中，w2 的梯度为什么只有 w1 梯度的一半？ ​

查看答案

平方误差下，参数的梯度 = 2×(预测−目标)×该参数对应的输入。w2 对应的输入 x2 = 0.5，只有 w1 的输入 x1 = 1.0 的一半，杠杆更短，所以梯度是 -0.5 对 -1.0。这也说明：某个输入越接近零，连着它的参数在训练中得到的调整信号越小。
