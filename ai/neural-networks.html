神经网络直觉 ​

一句话结论： 神经网络把许多可调的计算单元分层连接起来，通过损失函数提供方向，再用反向传播和梯度下降逐步调整权重与偏置。

前置知识 ​

  • 已阅读 机器学习入门，理解特征、标签、训练、验证和泛化。
  • 知道模型参数是在训练中调整的数字。
  • 不要求微积分基础；本页只解释计算方向，不推导偏导数和链式法则。

学习目标 ​

读完后，你应该能够：

  • 解释神经元、层、权重和偏置分别做什么。
  • 说明为什么神经网络需要激活函数。
  • 按顺序描述前向计算、损失计算、反向传播和参数更新。
  • 区分损失函数、梯度与梯度下降。
  • 说明神经网络与深度学习之间的关系。

核心概念 ​

神经元、权重和偏置 ​

人工神经元不是生物神经元的完整模拟，而是一个可训练的计算单元。它先对输入做加权求和，再加上偏置：

text
z = w1*x1 + w2*x2 + ... + wn*xn + b
输出 = 激活函数(z)
  • x 是输入特征或上一层输出。
  • w 是权重（Weight），决定每个输入影响有多大、方向是正还是负。
  • b 是偏置（Bias），让神经元不必在所有输入为零时也固定输出零。

训练神经网络的核心，就是找到一组能让预测误差更小的权重和偏置。

层与网络 ​

神经元通常按层组织：

  • 输入层：接收原始特征，本身通常不做复杂学习。
  • 隐藏层：逐层组合输入，形成更抽象的表示。
  • 输出层：产生分类概率、数值或其他任务输出。

一个网络可以有多个隐藏层。深度学习（Deep Learning）通常指使用多层神经网络从数据中学习分层表示的方法。“深”描述的是网络结构层次，不代表模型拥有更深刻的主观理解。

激活函数 ​

如果每层都只做线性加权，多层线性计算仍可合并成一次线性计算，网络很难表示弯曲的决策边界。激活函数（Activation Function）引入非线性。

常见函数包括：

  • ReLU：负数输出 0，正数保持不变；常用于隐藏层。
  • Sigmoid：把数值压到 0 与 1 之间；常用于二分类输出，但深层隐藏层中可能出现梯度过小。
  • Tanh：把数值压到 -1 与 1 之间。
  • Softmax：把一组原始分数（Logit，下一章的推理与解码页会细讲）转成总和为 1 的概率，常用于输出层。

激活函数的选择会影响表达能力、梯度传播和训练稳定性。

前向计算 ​

前向计算（Forward Pass）是从输入到输出依次计算：

  1. 输入进入第一层。
  2. 每个神经元计算加权和与激活值。
  3. 当前层输出成为下一层输入。
  4. 输出层给出最终预测。

推理阶段主要执行前向计算。训练阶段在前向计算后，还要比较预测与目标并更新参数。

损失函数 ​

损失函数（Loss Function）把“预测有多不对”变成一个可优化的数值。

  • 回归任务常用均方误差或平均绝对误差。
  • 分类任务常用交叉熵。
  • 生成模型会根据训练目标使用 Token 级交叉熵或其他损失。

损失越小通常表示模型更符合当前训练目标，但不代表真实业务一定更好。数据偏差、错误标签和不合适的目标函数都可能让“低损失”与“有用”分离。

反向传播与梯度下降 ​

**梯度（Gradient）**可以直观理解为：某个参数稍微变化时，损失会朝哪个方向、以多快速度变化。

**反向传播（Backpropagation）**从输出层向前计算每个参数对损失的影响。它高效复用了链式法则中的中间结果，本身负责“算梯度”。

**梯度下降（Gradient Descent）**使用这些梯度更新参数：

text
新参数 = 旧参数 - 学习率 * 梯度

学习率决定每次走多大一步。太大可能越过较好位置甚至发散，太小则训练缓慢。实际训练通常使用小批量数据和 Adam 等优化器，但核心直觉仍是沿着降低损失的方向更新参数。

最小推演：训练一个神经元 ​

假设一个神经元有两个输入：

text
x1 = 1.0, x2 = 0.5
w1 = 0.8, w2 = -0.4, b = -0.1

使用 ReLU 激活：

text
z = 0.8*1.0 + (-0.4)*0.5 - 0.1 = 0.5
预测值 = ReLU(0.5) = 0.5

若目标值是 1.0，使用平方误差：

text
损失 = (预测值 - 目标值)^2 = (0.5 - 1.0)^2 = 0.25

在这个位置，增大 w1 会让预测更接近目标。若学习率为 0.1，梯度计算得到 w1 的梯度为 -1.0（对平方误差，w1 的梯度 = 2×(预测−目标)×输入 = 2×(0.5−1.0)×1.0 = −1.0），则：

text
新 w1 = 0.8 - 0.1*(-1.0) = 0.9
新预测 = ReLU(0.9 - 0.2 - 0.1) = 0.6
新损失 = (0.6 - 1.0)^2 = 0.16

一次更新后损失从 0.25 降到 0.16。真实神经网络会同时更新大量参数，并在许多批次上重复这个过程；单次下降不保证最终一定泛化良好。

对比表 ​

把本页的核心概念放在一起对比：

概念回答的问题是否在训练中变化常见误解
权重（Weight）某个输入影响多大、方向如何是权重越大就一定越重要
偏置（Bias）整体激活门槛如何平移是与数据偏见或公平性中的 bias 完全相同
激活函数如何引入非线性或形成输出范围通常否任意激活函数都能互换
损失函数当前预测离训练目标多远公式通常固定，数值变化损失低就一定满足业务目标
梯度参数微调会怎样影响损失每步重新计算梯度就是参数更新后的值
优化器如何根据梯度更新参数状态会变化优化器能自动解决数据和目标错误

常见误区 ​

  • “神经元像人脑一样思考”：人工神经元是受启发的数学单元，不等同于生物神经系统。
  • “层数越多越好”：更深的网络需要合适的数据、结构、优化和正则化。
  • “反向传播就是梯度下降”：反向传播计算梯度，梯度下降或其他优化器使用梯度更新参数。
  • “激活函数只改变输出范围”：它还决定网络能否表达非线性关系，并影响梯度传播。
  • “训练损失下降就完成了”：还要检查验证指标、过拟合、鲁棒性和真实场景表现。
  • “Bias 一定指社会偏见”：本页 Bias 是神经元参数；数据偏差与公平性是另一层问题。

自测问题 ​

1. 为什么多层网络不能全部省略激活函数？ ​

查看答案

因为多层纯线性变换仍可合并成一次线性变换，无法表达复杂的非线性关系。激活函数让网络形成弯曲、分段或更复杂的映射。

2. 反向传播和梯度下降分别负责什么？ ​

查看答案

反向传播高效计算各参数对损失的梯度；梯度下降或其他优化器根据梯度和学习率更新参数。

3. 训练损失持续下降而验证损失开始上升，最可能说明什么？ ​

查看答案

最可能出现了过拟合：模型继续适应训练数据的细节，却降低了对未见数据的泛化能力。
