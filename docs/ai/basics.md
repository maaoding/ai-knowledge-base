# AI 基础概念

一句话：AI 是让机器从数据中学习规律并完成任务的一类方法，不等于“会思考的人”。

## AI、机器学习和模型

常见说法可以这样区分：

- AI：更大的概念，指让机器表现出某种智能能力。
- 机器学习：AI 的一类方法，让系统从数据中学习规律。
- 深度学习：机器学习的一类方法，使用多层神经网络学习复杂表示。
- 模型：学习后的参数和结构组合，用来做预测、生成、分类或决策。

当我们说“调用一个 AI 模型”时，通常是在给模型输入数据，让它根据训练中学到的规律输出结果。

## 训练和推理

训练是让模型学习的阶段。

训练时需要：

- 数据：文本、图片、音频、代码、标注结果等。
- 目标：希望模型学会什么，例如预测下一个词、识别图片类别、生成图片。
- 参数：模型内部可调整的数字。
- 损失函数：衡量模型输出和目标之间差距的方法。

推理是使用模型的阶段。用户输入 Prompt、图片或其他上下文，模型根据已有参数生成结果。大多数普通用户接触到的是推理，而不是训练。

## Token 和上下文

Token 是模型处理文本的基本单位。它不一定等于一个字或一个词，中文、英文、标点、空格都可能被拆成不同 token。

上下文窗口是模型一次能看到的 token 范围。它会影响：

- 能塞进去多少历史对话。
- 能否阅读长文档。
- 是否容易忘记前面信息。
- 输出成本和速度。

上下文越长不代表效果一定越好。无关信息太多时，模型反而更难抓住重点。

## Embedding

Embedding 是把文本、图片或其他对象转换成向量表示的方法。

直观理解：意思相近的内容，在向量空间里距离更近。它常用于：

- 搜索相似文档。
- 推荐相关内容。
- RAG 中检索知识片段。
- 聚类和去重。

Embedding 本身不直接回答问题，它更像“可计算的语义索引”。

## 参数、能力和限制

模型参数可以理解为模型内部保存知识和规律的数字。参数更多通常代表表达能力更强，但也带来更高的训练和推理成本。

评价模型时不要只看参数量，还要看：

- 训练数据质量。
- 架构和训练方法。
- 推理速度和成本。
- 上下文长度。
- 工具调用、结构化输出、多模态能力。
- 是否适合你的任务。

## 常见误区

- “AI 什么都懂”：模型会生成看似合理的内容，但可能事实错误。
- “模型越大越好”：任务简单时，小模型可能更快更便宜。
- “把资料全塞进去最好”：上下文需要筛选和组织。
- “联网就一定准确”：联网只是增加信息来源，不等于自动判断真假。
