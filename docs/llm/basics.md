# 大模型入门

一句话：LLM 是以大量文本和代码训练出来的语言模型，核心能力是根据上下文预测和生成后续 token。

## LLM 是什么

LLM 是 Large Language Model，大语言模型。它可以处理和生成自然语言，也常能处理代码、表格、结构化文本，部分模型还能理解图片、音频或视频。

它擅长：

- 总结、改写、翻译。
- 问答和解释。
- 代码生成和调试。
- 信息抽取和结构化。
- 规划步骤和辅助决策。

它不擅长：

- 自动保证事实正确。
- 长期稳定记住所有历史。
- 在缺少上下文时猜测私有信息。
- 对所有数学、逻辑和最新事实都零错误。

## 为什么它能对话

LLM 的基本训练目标通常是预测下一个 token。大量训练后，模型会学到语言模式、知识关联、代码结构、推理模板和交互习惯。

对话能力通常来自后续训练和对齐：

- 指令微调：让模型更会按人类指令回答。
- 偏好对齐：让模型更符合人类偏好的表达、安全和帮助性。
- 工具调用训练：让模型学会在需要时调用外部工具。

## Prompt 的作用

Prompt 不是命令开关，而是提供任务、上下文、约束和输出格式。

好的 Prompt 通常包含：

- 目标：要解决什么问题。
- 背景：必要上下文和材料。
- 约束：不要做什么、必须遵守什么。
- 输出格式：希望返回表格、列表、JSON 还是步骤。
- 判断标准：什么算完成。

## 幻觉和不确定性

幻觉是模型生成了看似合理但不真实的内容。它常出现在：

- 问题缺少上下文。
- 资料已经过期。
- 要求模型给出不存在的引用。
- 任务需要外部验证但没有提供工具。

降低幻觉的方法：

- 提供原始资料。
- 要求模型区分事实、推断和不确定。
- 对最新信息进行检索。
- 使用 RAG 或数据库查询。
- 对关键输出做测试或人工复核。

## LLM 应用的基本形态

常见应用可以分为几类：

- Chat：对话问答和写作辅助。
- Copilot：在具体软件或代码环境里辅助操作。
- RAG：先检索资料，再让模型基于资料回答。
- Agent：模型会规划步骤并调用工具。
- Workflow：把模型调用放进固定业务流程。

学习 LLM 时，不要只学聊天技巧，还要理解数据、工具、评估和失败模式。
