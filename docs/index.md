## 这份知识库适合谁

这份文档面向刚接触 AI 的人：你可能听过大语言模型、Token、Embedding、RAG、Agent、Stable Diffusion、ComfyUI、LoRA、FLUX，但还不清楚它们之间是什么关系。

知识库的目标不是堆链接，而是先把常见概念讲清楚。理解这些概念后，再去看教程、选模型、写 Prompt、搭工作流会省很多时间。

## 建议阅读顺序

1. 先看 [入门路线](/guide/getting-started)，建立总览。
2. 再看 [AI 基础概念](/ai/basics) 和 [大模型入门](/llm/basics)。
3. 继续理解 [Transformer](/llm/transformer)、[训练与对齐](/llm/training-alignment)，再学习 [Prompt 入门](/prompting/basics) 和 [常用工具](/tools/common-tools)。
4. 需要外部知识或自动执行时，再看 [RAG 与 Agent](/llm/rag-agent)。
5. 如果关注图像生成，进入 [AI 绘画专题](/concepts/base-model)；最后浏览 [常用网站](/resources/websites) 与 [精选教程](/resources/tutorials)。

## 内容边界

本文档按公开发布口径编写：

- 不提供盗版模型、侵权素材、绕过平台规则或规避安全限制的方法。
- 不以成人内容、攻击性用途、违法采集数据或滥用自动化为教程主线。
- 对模型、数据、素材和 API 的使用，优先建议查看许可证、模型卡、隐私条款和平台规则。
