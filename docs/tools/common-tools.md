# 常用工具

一句话：工具把模型、数据和流程包装成可用体验。选择工具时要同时看任务、隐私、成本、硬件、可控程度和维护负担。

## Web AI 助手

ChatGPT、Claude、Gemini 等 Web AI 助手适合快速问答、写作、总结、翻译、代码辅助和文件分析。

适合：

- 快速验证想法，不搭建技术环境。
- 处理一次性文本、表格、图片或代码任务。
- 使用平台提供的搜索、文件和多模态能力。

注意不要上传无权处理的隐私、商业机密或受限制数据，并核对平台当前的数据使用、费用和内容规则。

## API 与 SDK

API 适合把模型能力接入自己的应用或固定流程，例如分类、信息抽取、结构化输出、问答和工具调用。

实际项目还需要处理：

- 密钥和权限管理。
- 请求超时、限流、重试和错误记录。
- 输入输出校验，特别是 JSON 与 Function Calling 参数。
- 成本、延迟、模型版本和回归评估。
- 敏感数据脱敏与审计。

API 调用成功只代表请求完成，不代表结果已经正确。

## 本地模型工具

Ollama、LM Studio、llama.cpp 等工具可以在本地下载和运行兼容模型。

适合：

- 需要离线使用或更强的数据控制。
- 想比较不同开源模型和量化版本。
- 有合适的 CPU、内存或显卡资源。

本地运行仍要管理模型来源、许可证、磁盘空间、显存占用、上下文长度和推理速度。开源或本地不自动等于无限制使用。

## RAG 与 Agent 工具

LangChain、LlamaIndex、Dify 等工具可以组织文档检索、模型调用、结构化步骤和外部工具。

它们能减少重复开发，但不会自动解决：

- 文档切分和检索质量。
- 来源引用和版本管理。
- 工具权限、输入校验和失败恢复。
- Agent 循环、成本失控和不可重复行为。
- 评估样例与人工复核。

先用简单流程验证数据和任务，再决定是否需要完整 Agent 框架。

## AI 绘画工具

### Web 图像平台

适合快速体验和简单创作，不需要本地显卡。使用前检查额度、内容规则、上传素材隐私和商业许可。

### Stable Diffusion WebUI

按钮式本地 AI 绘画界面，适合传统 SD1.5 / SDXL 工作流、插件生态和常见图生图操作。

### ComfyUI

节点式工作流工具，适合学习模型数据流、精细控制、复用流程，以及搭建图生图、局部重绘、放大和参考图控制。

## 模型与资料管理

无论使用 LLM 还是图像模型，都建议记录：

- 模型名称、版本、来源和文件校验信息。
- 模型卡、许可证、推荐输入和用途限制。
- Prompt、参数、评估样例和已知失败模式。
- RAG 文档来源、更新时间、切分方式和索引版本。
- 工作流依赖、插件或节点版本。

## 图像后期与生产工具

AI 出图通常仍需要裁剪、调色、瑕疵修复、文字排版、放大和锐化。常见工具包括 Photoshop、Affinity Photo、Krita、Photopea 和 GIMP。

用于公开发布时，还应保留来源记录并做人工筛选。

## 如何选择

- 一次性体验：先用 Web AI 助手或图像平台。
- 固定应用流程：使用 API，并建立日志、校验和评估。
- 隐私或离线要求：评估本地模型和硬件成本。
- 经常查询自有资料：先做简单 RAG，再考虑 Agent。
- 需要精细图像控制：选择 WebUI 或 ComfyUI，并保留可复现工作流。
